========================================
LANGKAH INSTALASI
========================================

1. EXTRACT SOURCE
   mkdir -p /var/www/domain-anda
   tar -xzf billing-system-complete-2026-11-05-v1.2-final.tar.gz -C /var/www/domain-anda
   cd /var/www/domain-anda

2. BUAT DATABASE
   mysql -u root -p
   > CREATE DATABASE nama_database CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   > CREATE USER 'user_database'@'localhost' IDENTIFIED BY 'password_kuat';
   > GRANT ALL PRIVILEGES ON nama_database.* TO 'user_database'@'localhost';
   > FLUSH PRIVILEGES;
   > EXIT;

3. IMPORT DATABASE
   mysql -u user_database -p nama_database < database.sql

4. KONFIGURASI .env
   cp .env.example .env
   nano .env

   Isi:
   DB_HOST=localhost
   DB_NAME=nama_database
   DB_USER=user_database
   DB_PASS=password_kuat
   BASE_URL=https://domain-anda.com
   APP_ENV=production

5. SET PERMISSION
   chown -R www-data:www-data /var/www/domain-anda
   chmod 640 /var/www/domain-anda/.env
   chmod -R 755 /var/www/domain-anda/uploads
   chmod -R 755 /var/www/domain-anda/cache
   chmod -R 755 /var/www/domain-anda/logs

6. KONFIGURASI NGINX
   server {
       listen 80;
       server_name domain-anda.com;
       root /var/www/domain-anda;
       index index.php index.html;

       location / {
           try_files $uri $uri/ /index.php?$query_string;
       }
       location /portal {
           try_files $uri $uri/ /portal/index.php?$query_string;
       }
       location ~ \.php$ {
           include snippets/fastcgi-php.conf;
           fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
       }
   }

7. SETUP CRON (WAJIB)
   crontab -e

   Tambahkan baris berikut:

   # Cek status PPPoE online (tiap 5 menit)
   */5 * * * * /usr/bin/php /var/www/domain-anda/cron/check_pppoe_online.php >> /var/log/pppoe.log 2>&1

   # Cek status router (tiap 5 menit)
   */5 * * * * /usr/bin/php /var/www/domain-anda/cron/check_router_status.php >> /var/log/router.log 2>&1

   # Auto invoice (tiap 30 menit)
   */30 * * * * /usr/bin/php /var/www/domain-anda/cron/auto_invoice.php >> /var/log/invoice.log 2>&1

   # Cek jatuh tempo (tiap hari jam 00:00)
   0 0 * * * /usr/bin/php /var/www/domain-anda/cron/cek_jatuh_tempo.php >> /var/log/tempo.log 2>&1

   # Isolir pelanggan expired (tiap hari jam 01:00)
   0 1 * * * /usr/bin/php /var/www/domain-anda/cron/isolir_expired.php >> /var/log/isolir.log 2>&1

   # Disable pelanggan expired (tiap hari jam 02:00)
   0 2 * * * /usr/bin/php /var/www/domain-anda/cron/disable_expired.php >> /var/log/disable.log 2>&1

========================================
KONFIGURASI TAMBAHAN
========================================

MIKROTIK:
- Menu Router -> Tambah Router
- Isi IP, username, password
- Klik Test Connection

GENIEACS (opsional — BYO-ACS):
- Install GenieACS di server terpisah/lokal
- Settings -> GenieACS
- URL: http://IP-GenieACS:7557
- Username/password: kosongkan kalau tidak pakai auth

WHATSAPP:
- Settings -> WA Gateway
- Isi URL gateway, API key, nomor pengirim

TELEGRAM:
- Buat bot via @BotFather
- Settings -> Telegram
- Isi token bot

========================================
PAYMENT GATEWAY:
- Buka Settings -> Payment Gateway
- Provider yang SUDAH SIAP PAKAI: Duitku
- Provider di dropdown (siap dikembangkan): Midtrans, Xendit, Tripay, Paytren
- Cara aktifkan Duitku:
  1. Daftar di https://duitku.com
  2. Ambil Merchant Code & API Key dari dashboard
  3. Isi di Settings -> Payment Gateway
  4. Mode: sandbox (testing) / production (live)
  5. Set callback URL di dashboard Duitku ke: https://domain-anda.com/api/duitku_callback.php
  6. Klik Test Connection

CATATAN:
Integrasi fully-tested saat ini adalah Duitku.
Provider lain tersedia di dropdown untuk pengembangan lebih lanjut.

TROUBLESHOOTING
========================================
- Error "Failed to open stream": cek permission folder (langkah 5)
- Error koneksi DB: cek DB_HOST, DB_USER, DB_PASS di .env
- Cron tidak jalan: cek log di /var/log/*.log
- GenieACS tidak connect: pastikan port 7557 terbuka & URL benar
